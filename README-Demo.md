# 芯光数智官网运行与后台使用

官网与管理后台使用同一套后端接口。内容及图片保存在 MySQL，前端不使用浏览器本地存储维护管理数据。

## 首次运行

1. 安装 Node.js 20.19+ / 22.12+、Java 17+、Maven 3.9+、MySQL 8.0+。
2. 按 [数据库说明](database/README.md) 执行建库脚本及根目录 `init.sql`。
3. 按 [根目录 README](README.md) 设置 `XGSZ_DATABASE_URL`、`XGSZ_DATABASE_USER`、`XGSZ_DATABASE_PASSWORD`。
4. Windows 运行 `启动Demo.cmd` 打开官网，或运行 `启动后台.cmd` 打开控制台。首次构建需要下载依赖。
5. 首次访问后台，自行创建管理员账号及密码。

默认本地官网为 `http://127.0.0.1:8080/`，后台为 `http://127.0.0.1:8080/admin.html`，健康检查为 `/api/health`。关闭浏览器不会停止后端，运行 `停止项目.cmd` 结束服务；源码更新后先停止再重新启动。

源码手动构建见根目录 README。仅开发网页时，先运行后端，再在 `frontend/` 执行 `npm run dev`，本地开发入口为 `http://127.0.0.1:5173/`，`/api` 自动代理到后端 8080。正式部署将构建后的网页与后端打入同一个 JAR，具体见 [部署说明](docs/部署说明.md)。

## 后台内容维护

| 功能 | 维护范围 |
| --- | --- |
| 页面展示 | 首页、产品、服务、合作、关于、联系和全局文案 |
| 产品与服务 | 新增、编辑、删除、上下架，分类、卖点、图文和说明 |
| 展示资料 | 产品分类、品牌、证书、轮播、推荐产品、公司展示与合作方向 |
| 联系方式 | 电话、邮箱、地址、企业微信名称、联系链接及二维码 |
| 基础信息 | 备案、版权等企业公开资料 |
| 业务咨询 | 官网提交的需求与联系方式，标记待处理或已处理 |
| 管理员 | 后台账号维护；官网不提供客户注册、登录或订单功能 |
| 图片素材 | 上传 PNG/JPG/BMP，最大 5MB、长宽最多 4096 像素；存入数据库并取得站内图片地址 |

初始业务电话按已确认资料设置，其他联系方式留空。更新联系方式会同步联系页、页脚和咨询弹窗；填写备案不会清空电话、邮箱或地址。公司正式资料、实际产品配置和图片由后台补齐。

“页面展示 → 产品与解决方案”维护四个业务方向、细分分类、每行一项的型号或服务名称，以及淘宝、抖音链接；入口标识用于首页直达链接，修改标识时同步调整首页业务入口。当前线上平台链接使用平台首页，正式店铺确定后可直接替换。

“页面展示 → 关于我们”维护项目动态的时间、类型、标题、内容和顺序；可填写真实的交付地点、设备数量或优化事项。最新一条会显示在关于页首屏，完整时间线可继续查看。初始内容只记录官网建设进展，不生成虚构客户案例。

同一浏览器内的官网收到后台保存通知后刷新内容；其他浏览器在切回页面、切换栏目或最多约 30 秒后读取更新。公开接口仅返回已上架内容。产品筛选、滚动位置和未提交的咨询输入在同步时保留。

长文案、列表和不同比例图片已纳入响应式检查。页面列表最多 50 项，产品与服务明细最多 30 项，产品详情图最多 12 张；上传后仍应检查实际图片裁切和业务文案。

## 管理与持久化

密码采用 BCrypt 摘要，管理员使用 HttpOnly/SameSite Cookie 会话，写入操作包含 CSRF 校验。管理员被停用、删除或修改密码后旧会话失效；当前账号不能停用、删除或重命名自身。

内容维护包含版本检查，过期页面保存时提示冲突并保留输入。数据库是内容来源，后续启动不会重置已修改或已删除内容。`site_admin` 仅为旧管理员数据兼容表，新账号保存在 `Admins`。

备份使用公司自己的 MySQL 备份流程，部署前设置独立应用数据库账号。实际账号、连接密码、运行库、上传数据、日志及备份不提交 Git。当前不提供邮件、短信或企微消息通知。
