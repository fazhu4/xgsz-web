## 数据库交付

`database/create-database.sql` 创建 MySQL 数据库，根目录 `init.sql` 提供与运行时一致的 20 张表及公开初始内容。SQL 来源及维护方式见 [数据库说明](../database/README.md)。

本次交付的 3 项 SQL 回归测试和 SQL 来源一致性检查均通过。在独立 MySQL 库实际导入后核对了 20 张表、3 项产品、4 项服务、8 组页面、3 个分类及 3 项合作方向；初始无管理员和咨询，联系方式为空。开启 `NO_BACKSLASH_ESCAPES` 后重复导入也通过，中文和页面换行与原始 JSON 一致。

应用以 `spring.sql.init.mode=never` 启动成功，健康检查确认 MySQL；验证首次创建管理员、后台修改产品、新增服务、修改首页文案并通过公开接口读回。再次导入 SQL 以及重启应用后，账号、修改和新增内容仍保留，未出现重复初始数据。

## 复核命令

```sh
python scripts/generate-database-sql.py --check
python -m unittest discover -s scripts/tests -v
cd frontend
npm run build
cd ..
mvn -f website/pom.xml package
```

浏览器测试见 `frontend/tests/`；执行前按 `frontend/scripts/test-database.mjs` 的要求配置独立 MySQL 测试库，避免使用实际业务数据库。
