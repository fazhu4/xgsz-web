## 数据库交付

`database/create-database.sql` 创建 MySQL 数据库，根目录 `init.sql` 提供与运行时一致的 20 张表及公开初始内容。SQL 来源及维护方式见 [数据库说明](../database/README.md)。

本次交付的 3 项 SQL 回归测试和 SQL 来源一致性检查均通过。在独立 MySQL 库实际导入后核对了 20 张表、3 项产品、4 项服务、7 组页面、3 个分类及 3 项合作方向；初始无管理员和咨询，业务电话使用已确认号码，其余联系方式为空。此前开启 `NO_BACKSLASH_ESCAPES` 后重复导入也通过，中文和页面换行与原始 JSON 一致。

应用以 `spring.sql.init.mode=never` 启动成功，健康检查确认 MySQL；验证首次创建管理员、后台修改产品、新增服务、修改首页文案并通过公开接口读回。再次导入 SQL 以及重启应用后，账号、修改和新增内容仍保留，未出现重复初始数据。

控制台只保留业务方向与线上平台页面，按业务方向、细分分类和线上平台分组；管理员、产品和服务的编辑能力保留。首页、服务、合作、关于和联系等纯文案页面不再出现在控制台，也不会通过管理接口保存。

